Tarefa: Corrigir cálculo de "Saldo Atual" para usar saldo do período (igual ao Mobills)
Contexto
O "Saldo Atual" está mostrando o saldo histórico acumulado de todos os meses. Precisa mostrar apenas as transações pagas no mês selecionado (saldo do período), igual ao comportamento do Mobills. Exemplo: Itaú com salário R$8.780 recebido em junho e empréstimos R$2.881,11 pagos em junho → Saldo Atual = R$5.898,89, não o acumulado histórico.

Mudança 1 — server/routes/reports.routes.ts
No handler GET /api/dashboard/metrics, localize o bloco que calcula totalBalance somando todas as transações pagas. Ele provavelmente inclui um initialBalanceSum (soma de account.balance) adicionado ao paidSum sem filtro de data. Substitua por:

// Calcular saldo do período: soma das transações pagas no mês selecionado
// (mesmo critério do Mobills — não inclui histórico de meses anteriores).
let totalBalance = 0;
if (activeAccountIds.length > 0) {
  const balanceRows = await db
    .select({
      computedBalance: sql<string>`
        COALESCE(SUM(
          CASE
            WHEN ${transactions.type} = 'income' AND ${transactions.isPaid} = true THEN ${transactions.amount}::numeric
            WHEN ${transactions.type} = 'expense' AND ${transactions.isPaid} = true THEN -${transactions.amount}::numeric
            ELSE 0
          END
        ), 0)
      `,
    })
    .from(transactions)
    .where(and(
      eq(transactions.userId, userId),
      inArray(transactions.accountId, activeAccountIds),
      gte(transactions.date, start),   // <-- ADICIONAR filtro de data início do mês
      lte(transactions.date, end),     // <-- ADICIONAR filtro de data fim do mês
    ));
  totalBalance = parseFloat(balanceRows[0]?.computedBalance || '0');
  // NÃO adicionar initialBalanceSum — saldo do período não inclui offset histórico
}

As variáveis start e end já devem existir no mesmo handler (usadas para monthlyIncome/monthlyExpenses). Remova a soma de initialBalanceSum se existir.
